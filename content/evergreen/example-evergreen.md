# Example evergreen document (format only)

This file exists to show the front-matter format. It is loaded as a draft, so
the assistant never sees it. Replace it with the real File 02 documents.

Evergreen knowledge is information that normally stays valid across editions:
what the event celebrates, who can take part, how nominations work in general,
agency participation principles, and how the team handles sponsorship and
escalation. Anything that can change per edition (dates, fees, categories,
forms, jury, contacts, sponsors) belongs in the edition folder instead.
